    All Functions

    Every function and class in the toolbox, by category.

    Pipeline Stages

    Name Purpose
    INIT Read and filter instance metadata
    PRELIM Label good performance and normalise features and performance
    FILTER Remove near-duplicate instances to even out the instance density
    SIFTED Select the features that best explain algorithm performance
    PILOT Project instance features onto a 2D or 3D instance space
    PILOTviewpoint Find the best viewing angles of a 3D instance space
    CLOISTER Estimate the boundary of the instance space
    PYTHIA Train classifiers that predict which algorithms perform well
    TRACE Compute algorithm footprints in the instance space

    Class Interface

    Name Purpose
    InstanceSpace Build, explore and save an instance space

    Backward-Compatible Wrappers

    Name Purpose
    buildIS Build an instance space from a folder (backward-compatible wrapper)
    exploreIS Evaluate a saved instance space on new instances (backward-compatible wrapper)

    Utilities

    Name Purpose
    ISAdefaults Fill in missing options with their default values
    ISAvalidateOpts Check the type and range of user-supplied options
    ISAgetClassifierFcn Look up a classifier in the PYTHIA registry
    ISAmigrateModel Update a model from an earlier toolbox version to the current layout
    ISAsubsetData Keep a subset of the instances in a data structure

    Output

    Name Purpose
    scriptcsv Write the results of an instance space to CSV files
    scriptpng Save figures of an instance space as PNG files
    scriptweb Write colour-scaled data for the MATILDA web platform
    ISArecallView Return a 3D figure to its optimised viewpoint
