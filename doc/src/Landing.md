# InstanceSpace

This is a MATLAB toolbox for Instance Space Analysis (ISA): a methodology for assessing the strengths and weaknesses of algorithms by modelling the relationship between structural properties of a problem instance and algorithm performance, constructing "footprints" (regions of the instance space where an algorithm is inferred to perform well).
